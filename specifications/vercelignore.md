# vercelignore

- **File**: `.vercelignore`
- **Syntax**: gitignore
- **Source**: https://vercel.com/docs/projects/project-configuration
- **Reference**: gitignore

## Syntax

Uses gitignore syntax with no deviations to the pattern language.

## Deviations from gitignore

None (pattern syntax is identical).

## Notes

- Controls which files are excluded from Vercel deployments.
- Behaves identically to `.gitignore` for pattern matching purposes.
