# Виявлення мертвих правил проти живої файлової системи

- Літеральні шаблони перевіряються на існування, а глоби — бодай на один збіг, тож видалені шляхи проявляються як застарілі правила. Див. [довідник правил](docs/rules.md).
- Заперечені шаблони пропускаються, оскільки вони повторно включають, а не ігнорують.
- Шаблони поза деревом пропускаються без перевірки.
