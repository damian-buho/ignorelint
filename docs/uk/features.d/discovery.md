# Пошук усім деревом для монорепозиторіїв

- Без шляхів ignore-файли знаходяться самі: один каталог або все дерево з `--recursive`. Див. [довідник CLI](docs/cli.md).
- У знахідках — відносні до робочого каталогу шляхи у відсортованому порядку, тож вивід стабільний між запусками.
- Приховані каталоги, `node_modules` і символічні посилання пропускаються, тож внутрішнє, залежності й цикли посилань ніколи не перевіряються.
- Явно задані шляхи переважають пошук.
