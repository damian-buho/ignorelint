# Придушення для навмисних винятків

- Директива в коментарі вимикає перелічені коди для наступного шаблону, тож правильні записи перестають провалювати запуски. Див. [довідник правил](docs/rules.md).
- Директиви покривають усі коди, включно зі знахідками мертвих правил із файлової системи.
- Невідомі коди не збігаються ні з чим, тож директива з друкарською помилкою безпечна, а знахідка все одно з’являється.
- Придушені знахідки ніколи не доходять до автовиправлення чи кодів виходу.
- `--disabled-rules` (або `IGNORELINT_DISABLED_RULES`) пропускає перелічені коди на весь запуск, тож перевірка, з якою команда не згодна, перестає ламати збирання без построчних директив. Див. [довідник CLI](docs/cli.md).
