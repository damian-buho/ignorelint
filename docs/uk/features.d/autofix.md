# Автовиправлення, що зберігає зміст файлу

- `--fix` виправляє детерміновані проблеми на місці, тож прибирання відбувається без ручного редагування. Див. [довідник правил](docs/rules.md).
- Виправлення в одному рядку поєднуються за один прохід, тож один запуск дає кінцевий результат.
- Файли переписуються атомарно зі збереженням прав, тож перерваний запуск ніколи не лишить усічений файл.
- Заперечення ніколи не перевпорядковуються, а символічні посилання ніколи не переписуються, тож виправлення не може змінити те, що файл ігнорує.
- Виправлені знахідки позначаються заново й виключаються з рішення про збій, тож коди виходу відображають лише залишок.
